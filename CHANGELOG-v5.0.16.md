# BNK School OS v5.0.16 — Responsive Adaptive UI

## Added
- Global adaptive responsive layer for desktop, tablet, and phone.
- Off-canvas sidebar scrim and body scroll lock on tablet/mobile.
- Automatic mobile-card transformation for simple read-only `.table` data tables.
- Horizontal touch-scroll fallback for editable/complex tables.
- Full-screen mobile modal pattern with sticky header/action area.
- Procurement Master Form mobile layout: one-column fields, compact live summary, scrollable section pills, touch-size actions.

## Preserved
- v5.0.15 Shared Workspace permissions and procurement workflows.
- Green-to-gold hero visual language.
- Procurement 33-document PDF/A4 output and paper-sign workflow.
- All Supabase schema/RLS from v5.0.15; this release has no new SQL migration.
