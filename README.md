# BNK School OS — Procurement v5.0.15

ฐานต่อจาก v5.0.14 โดยแก้ Procurement ให้เป็น **Shared Workspace ของโรงเรียน** อย่างสมบูรณ์

## หลักสิทธิ์ใหม่
- Super Admin เปิดสิทธิ์ `ระบบเลขคุมเอกสารจัดซื้อจัดจ้างและพัสดุ` ให้ใคร → ผู้ใช้นั้นใช้งานฟีเจอร์ของระบบเลขคุมได้เต็มรูปแบบ
- Super Admin เปิดสิทธิ์ `ระบบจัดทำเอกสารจัดซื้อจัดจ้างและพัสดุ` ให้ใคร → ผู้ใช้นั้นเห็นและทำงานกับรายการจัดซื้อจัดจ้างกลางทั้งหมดได้ ไม่จำกัดเฉพาะงานที่ตนสร้าง
- ถ้าเปิดทั้งสองระบบ → ใช้งาน Workflow ตั้งแต่เลขคุม → Master Form → PDF → ทะเบียน ได้ครบ
- `created_by` และ `updated_by` ยังคงเก็บไว้เพื่อ Audit เท่านั้น
- การเปิด/ปิดสิทธิ์ให้ผู้ใช้อื่นยังเป็นหน้าที่ของ **Super Admin เท่านั้น**

## การยกเลิก/ลบรายการ
- `ยกเลิก` เก็บรายการไว้เป็นประวัติ
- `ลบ` เป็น Safe Delete: ซ่อนจากรายการใช้งานปกติ แต่ไม่ hard-delete row และไม่ปล่อยเลขคุมเดิมกลับมาใช้ซ้ำ
- รายการที่ยกเลิกแล้วสามารถลบต่อได้

## Database

`supabase-v5.0.15-procurement-shared-workspace.sql`
