# BNK School OS — Procurement v5.0.14

ฐานต่อจาก v5.0.13 โดยเพิ่มมาตรฐานส่วนหัวทุกระบบและการจัดการรายการจัดซื้อจัดจ้างแบบยกเลิก/ลบอย่างปลอดภัย

## สิ่งที่เพิ่มใน v5.0.14
- ส่วนหัวระบบหลักใช้ธีมเดียวกัน: เขียวไล่เฉดทอง + ลวดลายวงกลมโปร่งแบบระบบโครงการและงบประมาณ
- รายการจัดซื้อจัดจ้างมีปุ่ม `ยกเลิก` และ `ลบ` แยกกัน
- รายการที่ยกเลิกแล้วสามารถลบต่อได้
- การลบเป็น safe soft-delete เพื่อไม่ปล่อยเลขคุมเดิมกลับมาใช้ซ้ำโดยไม่ตั้งใจ
- มีตัวกรอง `ลบแล้ว` สำหรับตรวจสอบประวัติ

## Database
ถ้า v5.0.13 พร้อมแล้ว ให้รันเพิ่มเพียง:
