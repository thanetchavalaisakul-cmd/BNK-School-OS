## v5.11.3 — Procurement PDF: ลายเซ็น / ค่าปรับ / e-GP / รหัสภาษี

- หน้า “ประกาศ”: เพิ่มลายเซ็น 3 ฝั่ง — เจ้าหน้าที่ซ้าย / ผู้อำนวยการกลาง / หัวหน้าเจ้าหน้าที่ขวา
- ใบสั่งซื้อ/จ้าง: เพิ่มช่องอัตราค่าปรับต่อวัน (ร้อยละ) ใน Master Form; ค่าเริ่มต้น 0.20 และ PDF ใช้ค่าของแต่ละงาน
- หน้า “ตรวจรับ”: ตัดหัวหน้าการเงินและรองผู้อำนวยการออก; จัดเจ้าหน้าที่ / ผู้อำนวยการ / หัวหน้าเจ้าหน้าที่เป็น 3 ฝั่ง
- หน้า “ตรวจรับแบบ e-GP”: ใช้ช่องสี่เหลี่ยมจริง พร้อมโครงผลตรวจรับและค่าปรับแบบลำดับชั้น
- หน้า “เบิกจ่าย”: เหลือเฉพาะหัวหน้าการเงินและผู้อำนวยการ อยู่ข้างกันและกึ่งกลาง
- หน้า “ส่งเบิกเงิน”: เปลี่ยน “รหัสผู้ขาย” เป็น “รหัสภาษีร้านค้า” และใช้เลขภาษี/เลขบัตรประชาชนจากทะเบียนผู้ขาย
- ไม่มี Supabase Migration ใหม่: ค่าปรับเก็บใน `form_data` JSONB เดิม และรหัสภาษีมีอยู่ใน Master Vendor แล้ว

## v5.10.1 — ระบบโครงการและงบประมาณ
คณะกรรมการตรวจรับ 3 คนสามารถเลือกบุคลากรจาก **ทุกฝ่ายในโรงเรียน** ได้แล้ว ไม่บังคับฝ่ายเดียวกับผู้ขอเบิก โดยยังคงกฎ:
- กรรมการแต่ละคนต้องไม่ซ้ำกัน
- ผู้ขอเบิกห้ามเป็นกรรมการตรวจรับคำขอของตนเอง
- บัญชีกรรมการ PA เฉพาะระบบ (`pa_evaluator`) ไม่อยู่ในรายชื่อ
- เก็บ Snapshot ชื่อ ตำแหน่ง และฝ่ายของผู้ถูกเลือก ณ ตอนมอบหมาย

## PA workflow
1. ครูตั้งค่า **ข้อมูลส่วนตัวสำหรับเอกสาร PA** ของปีงบประมาณนั้น
2. ครูส่ง PA ต้นปี: PA 1 หน้า หรือ PA ฉบับเต็ม
3. ครูส่งรายงานผล PA ปลายปี
4. กรรมการ PA 3 คนประเมิน PA2 ผ่าน Rubric 60 + 40
5. เมื่อ PA2 ครบ 3/3 ระบบเปิด PA3 และสร้างแบบ PA 3/ส จากผลจริงอัตโนมัติ

## ข้อมูลส่วนตัวสำหรับเอกสาร PA
ครู/หัวหน้ากลุ่มงานที่เป็นผู้ส่ง PA มีการ์ดตั้งค่าของตนเองต่อปีงบประมาณ:
- รับเงินเดือนในอันดับ ครูผู้ช่วย / คศ.1 - คศ.5
- อัตราเงินเดือน
- วันที่อัตรานี้มีผล (ถ้ามี)
- อนุญาตให้ PA ใช้ลายเซ็นหลักอัตโนมัติในปีนั้น

ข้อมูลเงินเดือนไม่เก็บเป็นค่ากลางเดียว แต่ผูกกับปีงบประมาณ และเมื่อรายงานผลถูกส่งจะเก็บ Snapshot เพื่อให้ PA3 ปีเก่าไม่เปลี่ยนตามเงินเดือนปีใหม่

## ลายเซ็นครู
v5.10.0 **ไม่สร้างระบบลายเซ็นครูซ้ำ** แต่ใช้ระบบกลางของ BNK School OS:
- `signatures`
- `user_signature_preferences`
- หน้า `ลายเซ็นของฉัน`

Auto Sign สำหรับ PA ต้องมีทั้ง:
1. ลายเซ็นหลัก + เปิด Auto Sign กลาง
2. เปิด “อนุญาตให้ระบบ PA ใช้ลายเซ็นของฉันอัตโนมัติ” สำหรับปีงบประมาณนั้น

เมื่อครบเงื่อนไข:
- PA 1 หน้าที่ระบบสร้าง: ลงชื่อเมื่อส่ง
- รายงานผล PA: ลงชื่อผู้รายงานผลเมื่อส่ง
- PA ฉบับเต็มที่อัปโหลด: ไม่แก้/ประทับไฟล์ต้นฉบับ
- PA3: ไม่เพิ่มลายเซ็นครู เพราะแบบ PA3 ใช้ลายเซ็นกรรมการตาม workflow PA2

## PA2 / PA3
- PA2: 60 + 40 = 100 ตามโครงเดิม
- PDF PA2: รายกรรมการ / 3 กรรมการของครู 1 คน / ทั้งโรงเรียน
- PA3: ดึงคะแนน PA2 3/3 อัตโนมัติ ไม่กรอกคะแนนซ้ำ
- PDF PA3: รายครู / ทั้งโรงเรียน
- PA3 ต้องมี salary Snapshot ก่อน Export เพื่อไม่สร้างแบบราชการที่ข้อมูลเงินเดือนว่าง
