# BNK School OS v5.9.0

ล่าสุด: ระบบ PA ครบ workflow ตั้งแต่ PA ต้นปี → รายงานผลปลายปี → PA2 กรรมการ 3 คน → PA3 สรุปผล พร้อม PDF Export รายกรรมการ รายครู และทั้งโรงเรียน

## PA workflow
1. ครูส่ง PA ต้นปี: PA 1 หน้า หรือ PA ฉบับเต็ม
2. ครูส่งรายงานผล PA ปลายปี
3. กรรมการ PA 3 คนประเมิน PA2 ผ่าน Rubric 60 + 40
4. ผล ชื่อ ตำแหน่ง บทบาท และลายเซ็นกรรมการถูก Snapshot ตอนส่งผล
5. เมื่อ PA2 ครบ 3/3 ระบบเปิด PA3 และสร้างแบบ PA 3/ส จากผลจริงอัตโนมัติ

## PA2 PDF Export
- **รายกรรมการ**: ครู 1 คน + กรรมการ 1 คน
- **กรรมการทั้ง 3 คน**: ครู 1 คน รวมผลทั้ง 3 กรรมการในไฟล์เดียว
- **ทั้งโรงเรียน**: รวม PA2 ของครูที่ประเมินครบ 3/3 เป็น PDF เดียว
- ผู้ที่ยังประเมินไม่ครบจะไม่ถูกสร้างเป็นเอกสารเสมือนว่าประเมินเสร็จ ระบบจะแจ้งก่อน Export
- ใช้ Snapshot ลายเซ็น/ชื่อ/ตำแหน่งของผู้ประเมินจากวันที่ส่งผล

## PA3 / PA 3/ส
PA3 ไม่ให้กรอกคะแนนซ้ำ แต่สร้างจาก PA2 โดยตรง:
- คะแนนส่วนที่ 1 /60 ของกรรมการคนที่ 1-3
- คะแนนส่วนที่ 2 /40 ของกรรมการคนที่ 1-3
- คะแนนรวม /100 ของกรรมการคนที่ 1-3
- สถานะภาระงาน
- ผลผ่าน/ไม่ผ่าน
- ลายเซ็น Snapshot ของประธานกรรมการและกรรมการอีก 2 คน

รองรับ:
- Export PDF PA3 รายครู
- Export PDF PA3 ทั้งโรงเรียน
- Dashboard PA3 แบบ Master–Detail

> ฐาน Personnel ปัจจุบันไม่มีข้อมูลอัตราเงินเดือน จึงไม่เดาตัวเลขลง PA3; ช่องอัตราเงินเดือนแสดงเส้นประไว้ตามแบบเอกสาร ส่วนอันดับเงินเดือนใช้ข้อมูลวิทยฐานะที่มีอยู่เมื่อสามารถระบุได้

## บัญชีกรรมการ PA
Production มี Login ถาวร 3 ช่อง:
- `pa1@bnkschool.example`
- `pa2@bnkschool.example`
- `pa3@bnkschool.example`

บัญชีเหล่านี้ใช้เฉพาะระบบ PA กรรมการกรอกชื่อ ตำแหน่ง หน่วยงาน และเซ็นในระบบ/อัปโหลด PNG ได้ ลายเซ็นเก็บใน Private Storage

## คณะกรรมการกลาง
- ตั้ง 3 คนครั้งเดียวต่อปีงบประมาณ
- ประธานกรรมการ 1 คน + กรรมการ 2 คน
- ใช้ชุดเดียวกันกับครูทุกคน
- เปลี่ยนตัวบุคคลในปีถัดไปได้โดย Super Admin รีเซตโปรไฟล์กรรมการ ขณะที่ประวัติปีเก่ายังคง Snapshot เดิม
